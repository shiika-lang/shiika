# AST

Directory: `lib/shiika_ast`

AST (Abstract Syntax Tree) is generated by the parser.

## Structures

- `shiika_ast::Program` is the root; it holds `toplevel_items`, each
  of which is a definition (`Definition`) or an expression
  (`AstExpression`).
- `Definition` covers class/module/enum/method/constant definitions.
- `AstExpression` = `AstExpressionBody` + `LocationSpan` (the source
  location, used for error reporting).
- `AstPattern` represents patterns of `match` expressions.

Unlike HIR, the AST has no type information. Also, names (of
constants, classes, methods) are not resolved yet; e.g. a capitalized
name is stored as `UnresolvedConstName` and resolved during HIR
generation.

`AstVisitor` provides a way to traverse an AST (used by e.g. the
language server).
